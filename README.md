# Cold Outreach Pipeline for B2B SaaS

## About

This repository contains my research and a practical playbook for building an effective cold outreach pipeline for B2B SaaS companies.

Rather than relying on a single expert, I researched ten experienced practitioners across cold email, LinkedIn outreach, prospecting, and outbound sales. I compared their recommendations, identified areas of agreement and disagreement, rejected ideas that were not suitable for my goals, and developed my own recommendations.

This repository was created as part of the 100Hires hiring assessment.

## Research Methodology

The playbook was created using the following process:

1. Selected ten recognized outbound sales experts.
2. Reviewed LinkedIn posts, YouTube videos, podcasts, and blogs.
3. Summarized key insights.
4. Compared conflicting opinions.
5. Selected recommendations supported by evidence.
6. Added my own ideas where appropriate.

## Key Takeaways

- Personalization is more effective than generic outreach.
- Clear value propositions increase reply rates.
- Cold outreach should be treated as a repeatable process.
- Continuous testing is necessary.
- Different experts recommend different strategies depending on the situation.
