# Cold Outreach Pipeline for B2B SaaS

## About

This repository contains my research and playbook on building an effective cold outreach pipeline for B2B SaaS companies.

Rather than relying on a single expert, I researched ten experienced practitioners across cold email, LinkedIn outreach, prospecting, and outbound sales. I compared their ideas, identified areas of agreement and disagreement, rejected recommendations I did not believe were universally applicable, and created my own framework.

This repository was created as part of the 100Hires assessment.

## Key Takeaways

- Personalization beats mass outreach.
- Clear value propositions outperform feature-heavy emails.
- Continuous testing is essential.
- Multi-channel outreach is becoming more effective than email alone.
- There is no universal template that works for every prospect.
